# Rupas Barakam — Anime-inspired Developer Portfolio

A responsive, single-page portfolio inspired by dark fantasy anime aesthetics. Built with semantic HTML, CSS, and vanilla JavaScript (no build step required).

## Run locally

Open `index.html` in a browser, or use VS Code Live Server for a local development server.

## Personalize before publishing

- Add your resume PDF and update the `Download Resume` link if you decide to include one.
- Replace the Online Quiz System and Web Messenger repository links with their exact repository URLs if they differ.
- Confirm your LinkedIn URL and contact email.
- The hero art is a cropped concept image in `assets/awakening-art.png`; replace it with your preferred original anime-inspired artwork if desired.

## Deploy

You can deploy this folder directly to Netlify, GitHub Pages, or any static hosting provider.


### Achievements and certificates

The Achievements section includes clickable milestone cards. Select a card to open its certificate/photo in a lightbox; click the backdrop, use the close button, or press Escape to dismiss it. Certificate/photo images are stored in `assets/`.
